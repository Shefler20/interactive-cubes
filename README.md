# Интерактивные кубики

Интерактивное приложение, разработанное с использованием React, TypeScript и Vite.

## Возможности

- Перемещение двух кубиков внутри поля размером 800×800 px.
- Перетаскивание кубиков по горизонтали и вертикали.
- Ограничение перемещения границами поля.
- Выбор кубика и изменение его цвета.
- Автоматическое прилипание кубиков при сближении.
- Совместное перемещение прилипших кубиков.
- Разъединение кубиков со случайным расположением.

## Используемые технологии

- React
- TypeScript
- Vite
- CSS

## Установка и запуск

Клонировать репозиторий:

```bash
git clone <ссылка-на-репозиторий>
```

Перейти в папку проекта:

```bash
cd <название-папки>
```

Установить зависимости:

```bash
npm install
```

Запустить проект в режиме разработки:

```bash
npm run dev
```

## Сборка проекта

Создать production-сборку:

```bash
npm run build
```

Запустить предварительный просмотр production-сборки:

```bash
npm run preview
```
